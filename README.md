# Hola, soy David Dávila 👋

Product Owner especializado en banca digital. Diseño métodos para que los equipos
escriban historias de usuario claras, completas y verificables — y los automatizo con IA.

## Proyectos

**[story-forge](https://github.com/davilafon-popm/story-forge)** — Método y plugin de Claude
para redactar historias de usuario casi finales a partir de requerimientos y diseños,
en cualquier idioma y con cualquier gestor de tickets, wiki y herramienta de diseño
(Jira, Azure DevOps, Linear, Confluence, Notion, Figma, Penpot…).

- Revisión de alcance antes de redactar
- Criterios Dado/cuando/entonces con una imagen del diseño bajo cada uno
- Base de conocimiento por mercado que aprende de los bugs de cada sprint
- Alternativas para cada paso frágil (cuotas, permisos, interfaces)
